    我想使用¶

    文档 解决的问题
    快速上手 怎么安装、运行示例、在 Rust 中依赖本仓库
    多路信号管线 怎么质检、同步、保留历史窗口、组织训练输入
    MCAP 与媒体 怎么读 JSON、接 CDR/Protobuf、处理图片、检查视频
    Python API 14 个公共处理函数的签名、返回类型、默认值与错误
    Rust API 类型、模块、筛选接口、Decoder 扩展点
    算子清单 哪些已经实现，哪些能从 Python 调用

    文档描述 0.1.0 的实际接口。性能报告是历史证据，新增功能或实验应增加新记录， 不应覆盖旧测量。原始 profile 大文件在配置的 Linux 执行环境的 .artifacts/ 中，Git 中保存日志、 摘要、哈希与来源路径，详见证据索引。
